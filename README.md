# doclo

> **Status: experimental (beta).** doclo is in early development and nothing in this repository is stable or ready for
> production use. Interfaces, file formats and the command line will change without notice, and there is no working
> release yet. The package names reserved on PyPI and npm are placeholders. It is built in the open, partly by coding
> agents using [AI Loop Kit](https://github.com/gwpicard/ai-loop-kit), which is itself experimental.

doclo is a local application in which Claude generates branded slides and documents as PDF, a deterministic rulebook and
a screenshot loop make Claude fix its own violations, and your feedback becomes durable brand rules.

- The design is in [`docs/DESIGN.md`](docs/DESIGN.md), and the order of work is in [`docs/BUILD-PLAN.md`](docs/BUILD-PLAN.md).
- The piece map is in [`docs/ROADMAP.md`](docs/ROADMAP.md).
- Work lands first on the `loop/v0` branch and reaches `main` through reviewed pull requests.
